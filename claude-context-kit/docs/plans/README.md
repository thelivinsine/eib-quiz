# Plans

One document per body of work, written **before** it was built. Each says what the work was going to
be; each is marked shipped where it shipped, and none has been rewritten to agree with the code.

**A plan document is never deleted** — not when it ships, not ever. It is the only document here
that can be *wrong on the record*, and the wrong parts are the valuable ones: every other document
is written afterwards and is therefore correct by construction.
→ [`../decisions/process.md#a-plan-document-is-never-deleted`](../decisions/process.md#a-plan-document-is-never-deleted)

A rule that came out of a plan is **copied** into [`../decisions/`](../decisions/), never moved,
because rules are read from there.

**A plan is two documents**: `<name>.md` is the plan, `<name>-tasks.md` is its task list — numbered
items, what *done* means for each, and what has to land first.
→ [`../decisions/process.md#a-plan-and-its-task-list-are-two-documents`](../decisions/process.md#a-plan-and-its-task-list-are-two-documents)
