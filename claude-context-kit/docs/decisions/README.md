# Decisions

Why the rules are what they are. Every entry is the same three things: **the decision, the reason,
and what it cost.** The rules themselves live in [`../../CLAUDE.md`](../../CLAUDE.md), stated as
rules with no argument attached; this folder is the argument.

Words this project uses in a particular way are defined once in
[`../glossary.md`](../glossary.md).

Append new entries. When one is reversed, leave a short note here naming what replaced it and move
the argument to [`../archive/decisions.md`](../archive/decisions.md), so the live files do not fill
up with dead rules. **Headings are load-bearing** — code comments across the app point at them by
name, so rewrite a body freely and rename a heading only on purpose.

> **The tables below are empty on purpose.** Add one row per decision file as it is written, grouped
> under a heading that suits this project. The three groups kept below are a starting shape, not a
> requirement — rename them, or use one table, if that is what the project turns out to need.
