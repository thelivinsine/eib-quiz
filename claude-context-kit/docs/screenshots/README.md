# Screenshots

One folder per body of work, in the order it was built. A shot is filed by **what it
shows**, not only by the date in its name — where one day carried two bodies of work, the
date alone cannot place a shot and the folder has to.

Names are `YYYY-MM-DD-what-it-shows.png`. Raw captures dropped into a session as feedback
keep the name the operating system gave them (`Screenshot YYYY-MM-DD HHMMSS.png`); they are
**not** renamed after the fact, and the folder is what places them.

**Where two folders are easy to confuse, write the tell into this file** — the one visible
difference that says which build a shot came from. It is found by opening the screenshots,
not by reading the dates.

layout only.
