# Arabic terminology (العربية)

**Purpose.** The catalogue repeats the same civic terms across hundreds of questions. Every
batch of Arabic translation uses this list, so one German term never comes out three
different ways, and a reviewer can check each term once rather than in every question.

**Summary.**

- One fixed Arabic rendering per German term, below. A translation uses it exactly.
- **Titles that appear side by side as answer options must stay distinguishable.** The
  catalogue puts Bundeskanzler, Premierminister, Ministerpräsident and Regierungschef next to
  each other as wrong answers, so each has its own rendering here.
- The reviewer checks this list first: a wrong term here is wrong everywhere.

## Rules for every batch

- **Translate from the German**, using the English only to resolve doubt.
- **Keep as written**: names of people and places, party abbreviations (CDU, SPD, FDP),
  dates, numbers and the names of the sixteen states as the language file's state list gives
  them.
- **A German institution with no equivalent keeps its German name in brackets** the first
  time it appears in a question, as the list below does for Ordnungsamt.
- **Modern Standard Arabic**, as read across Syria, Iraq and Morocco, not a dialect.
- **Feminine titles take the feminine form** where the German uses -in (رئيسة البلدية).
- **Digits stay Western (0-9)**, as the exam prints them.
