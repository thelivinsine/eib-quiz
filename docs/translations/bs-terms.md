# Bosnian / Croatian / Serbian terminology (Bosanski / Hrvatski / Srpski)

**Purpose.** The catalogue repeats the same civic terms across hundreds of questions. Every
batch of Bosnian / Croatian / Serbian translation uses this list, so one German term never comes out three
different ways, and a reviewer can check each term once rather than in every question.

**Summary.**

- One fixed Bosnian / Croatian / Serbian rendering per German term, below. A translation uses it exactly.
- **Titles that appear side by side as answer options must stay distinguishable.** The
  catalogue puts Bundeskanzler, Premierminister, Ministerpräsident and Regierungschef next to
  each other as wrong answers, so each has its own rendering here.
- The reviewer checks this list first: a wrong term here is wrong everywhere.

## Rules for every batch

- **Translate from the German**, using the English only to resolve doubt.
- **Keep as written**: names of people and places, party abbreviations (CDU, SPD, FDP),
  dates, numbers and the names of the sixteen states as the language file's state list gives
  them.
- **A German institution with no equivalent keeps its German name in brackets** the first
  time it appears in a question, as the list below does for Ordnungsamt.
- **Bundeskanzler is savezni kancelar, never premijer.** Premijer is reserved for Premierminister, which the catalogue uses as a wrong answer beside Bundeskanzler, and premijer pokrajine for Ministerpräsident.
- **One Latin-script, ijekavian text** for Bosnian, Croatian and Serbian readers. Prefer a word shared by Bosnian and Croatian and understood by Serbian readers. Where the three differ, the Bosnian form below is the one a question uses; the Croatian (hr.) and Serbian (sr.) forms in square brackets are for the reviewer only and never appear in a question.
- **Address the reader as vi**, the polite form, never ti.
- **Write č, ć, đ, š and ž**, never c, d, s or z in their place.
